# EPF Week 16 - Ivan Anishchuk - extending the FOCIL + ePBS result network-wide

Short version:

- Extended the FOCIL + ePBS result from week 14 from one node to every honest node, and from one
  slot to the slots after the block.
- Proved that the beacon-chain shuffle is a permutation and that the committees partition each
  epoch.

## Faithfulness

[#134](https://github.com/etheorem/etheorem/pull/134) makes the model raise where the pinned pyspec
raises: `uint64` overflows, out-of-range reads and asserts, in fork choice, the shuffle and
committees, epoch processing and block operations. Each area has pin tests that replay the pyspec
outcome. The PR also removes the eth1 deposit path that Fulu dropped and adds the EIP-7892 blob
schedule. The proof PRs are stacked on top of it.

## Every honest node

[#135](https://github.com/etheorem/etheorem/pull/135) covers the gaps left in week 14. The
`get_head` walk avoids the payload over the whole loop. Each node is a trace of fork-choice handler
runs, so most of the week 14 assumptions about the store are now proved. The result holds at every
honest node in the slot after the block, including a node that never received the payload. Honest
attesters in that slot don't vote for the payload, and honest proposers build without it.

## The slots after

From the second slot on, attestation weight decides between the FULL and EMPTY branches.
[#136](https://github.com/etheorem/etheorem/pull/136) models this as a race and connects the model
to the spec's weight functions. EMPTY stays ahead while honest committee balance beats the
adversary plus the proposer boost in the first slot, and matches the adversary after that. More
than 70 % honest balance in the first committee is enough for the first slot.

[#137](https://github.com/etheorem/etheorem/pull/137) proves that `compute_shuffled_permutation`
is a permutation for any seed and hash, and that each active validator sits in exactly one
committee of an epoch. The race uses this to count each validator's vote once within an epoch.

[#138](https://github.com/etheorem/etheorem/pull/138) composes the pieces and adds a two-node test
run at the minimal preset that meets the premises.
